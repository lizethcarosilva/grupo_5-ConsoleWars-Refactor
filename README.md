# Console Wars — Grupo 5
Blog comparativo **Xbox vs PlayStation** del taller de Generation Colombia (SCRUM).  
Refactor con HTML, CSS, Bootstrap 5 y componentes reutilizables.

## Cómo verlo
No abras el HTML con doble clic. Desde la raíz del proyecto:
```bash
python -m http.server 5500
```
O usa **Live Server** en VS Code / Cursor. Luego abre `http://localhost:5500`.
